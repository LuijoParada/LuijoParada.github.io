Melody

Melody: Unlock Your Musical Potential with AI. This thesis project is an innovative web application for basic music learning. Its most innovative feature is an intelligent converter that, thanks to the integration of the Basic Pitch model (implemented with Python and Keras), transforms monophonic audio into precise PDF sheet music. The application also offers music theory, interactive exercises with progress tracking, and a login system with roles (user, admin, superadmin) to save transcriptions and progress.

Developed as a Single Page Application with Angular 19, "Melody" prioritizes a fluid and agile user experience, featuring an attractive interface thanks to custom CSS components and efficient communication with the backend using Axios. The backend, built with Laravel and its MVC architecture, exposes a robust API. The management of users, sheet music, and exercises is done with an SQLite database, while integration with a CDN for file management (MP3, MIDI, PDF) was planned for a future production environment.

Php Inventory

Created a robust and user-friendly inventory management application using PHP to significantly improve stock control and operational efficiency. This system offers an intuitive interface for administrators to perform essential inventory tasks with ease. Adding new products involves capturing comprehensive details, while updating existing inventory allows for modifications to quantities, descriptions, pricing, and other relevant information.

The system also facilitates the removal of discontinued or sold-out items. To ensure organized inventory, a category management feature allows for the creation, modification, and deletion of product categories. Crucially, the application incorporates a secure user management module, enabling the creation of new user accounts with specific roles and permissions, the modification of existing user details, and the removal of accounts, thereby safeguarding sensitive inventory data and controlling system access.

Notes PWA

This note-taking application is a Progressive Web Application (PWA) crafted solely using JavaScript. It delivers a user-friendly platform for creating, editing, and organizing notes. By adhering to PWA principles, it offers features like installability, offline availability of notes, and a responsive layout. The development process involved a strong focus on utilizing JavaScript for all aspects, including managing data persistence through local storage, dynamically updating the user interface, and implementing service workers to enable offline capabilities and enhance the overall user experience.

Coffee Shop

For a coffee shop, I developed a comprehensive Single Page Application (SPA) that offers an intuitive interface for browsing the menu and placing online orders. The application allows users to easily navigate through different product categories and add items to their order. This project was built using only JavaScript, which allowed me to delve deeply into the application of advanced patterns and concepts such as template manipulation for dynamic interface generation, the creation of Web Components to encapsulate functionality and improve code reusability, the implementation of a routing system for navigation without page reloads, and other design principles that are fundamental in the development with popular JavaScript frameworks.
